# CrimeTime Studio: connection and posting feedback

Target: the existing Electron app, including Studio and Instagram. The separate ig-studio work was reverted after Cory corrected the project scope.

UI references inspected before edits:
- Fourthwall post management: https://refero.design/pages/f1de042b-ce32-4144-a3a7-1b8048bd084e
- Anthropic library: https://refero.design/pages/976ca247-62c6-4a8c-9eb2-0a1fe4e30e26

Constraints: retain Bebas Neue headings, Inter body, and IBM Plex Mono metadata. Retain the existing black, red, and tape-yellow palette. Keep the existing 8/14/22px control and header spacing and focus rings. Add no decorative motion. Use explicit connection, checking, retry, and error states within the existing account controls.

Scope: repair Instagram session lookup, refresh stale account status, preserve profile checks before opening a composer, and propagate command failures. Do not publish, change accounts automatically, or alter podcast drafts.

Validation: 54 Studio checks and seven shell tests passed, including an isolated real Electron window. Reviewed the captured account controls, error feedback, and retained caption edits. The fixture uses local content and blocks external font requests; it does not validate a live Instagram login or publish a post. Existing running windows need a restart to load the updated main process.
